# Submission starter

Replace this starter with your implementation. Keep authored inputs outside the generated
roots listed in `instruction.md`. The verifier deletes those roots and invokes exactly:

```bash
bash /home/submission/reproduce.sh
```

Replay is offline and runs as uid/gid 65532. Respect `PBX_MAX_WORKERS` when creating workers.
Leaving this starter unchanged, or omitting `reproduce.sh`, records a non-delivered submission.
It is not a completed measurement.
